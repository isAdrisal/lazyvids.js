# lazyvids.js

A small utility to lazy-load autoplay HTML5 videos once they enter the viewport.

## Installation

Install using your favourite package manager.

```shell
$ npm install lazyvids
```

Import into your project.

```js
import 'lazyvids';
```

## Usage

Refer to the Github Repository for full usage [documentation](https://github.com/isAdrisal/lazyvids.js#readme).
